## 4. Realtime Gateway & Reverse Proxy Matrix

### Unified Realtime Gateway (`apps/api-gateway/src/encore_gateway/routers/realtime.py`)
- **WebSocket Gateway (`ws://localhost:8000/ws`):**
  - Multiplexed channel subscriptions using `WsEnvelope` frames:
    - Client sends: `{"type": "subscribe", "channel": "order:123"}`
    - Server confirms: `{"type": "ack", "channel": "order:123"}`
    - Heartbeat ping/pong: `{"type": "ping"}` -> `{"type": "pong"}`
- **SSE Fallback (`http://localhost:8000/ws/sse`):**
  - Server-Sent Events streaming transport fallback with periodic keepalive pings.
- **Cross-Gateway Coordination:**
  - Redis Pub/Sub listener on `realtime:*` channels for horizontal scale-out.
  - Background Kafka consumer bridge subscribing to 12 domain topics:
    `waiting-room.admitted`, `inventory.seat.held`, `inventory.seat.released`, `inventory.seat.sold`, `orders.created`, `orders.completed`, `orders.cancelled`, `payments.succeeded`, `payments.failed`, `resale.trade.completed`, `resale.listing.created`, `chat.message`.

### Reverse Proxy Configuration
- `http://localhost:8000/api/v1/resale/*` -> Proxies to `http://encore-resale-engine:8007`
- `http://localhost:8000/api/v1/wallets/*` -> Proxies to `http://encore-wallet-service:8008`
